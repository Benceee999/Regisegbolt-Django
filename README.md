# Antique Online Auction House (Régiségbolt)

A web application built with Python and Django for an online antique auction house. The platform features categorized antique cataloging, automated and user-driven bidding mechanisms, role-based access control, and public customer feedback.

## Features

- **Item Catalog & Filtering:** Browse antique items (paintings, jewelry, porcelain) with server-side pagination and search.
- **Auction & Bidding System:**
  - Real-time bid validation (bids must strictly exceed the current highest bid).
  - Authentication guard: only logged-in users can place bids.
  - Auctioneer role (`is_auctioneer` / `Arverezo` group): authority to open and close auctions.
  - Winner designation and final hammer price display upon auction conclusion.
- **Administration:** Django Admin integration for managing inventory, tracking closed auctions, and handling media/static image storage.
- **Customer Feedback:** Public contact form with persistent feedback storage and listing.
- **Testing & Error Handling:** 5 comprehensive Django `TestCase` unit tests covering bidding constraints, permissions, and custom 404 page handling.

## Tech Stack

- **Backend:** Python 3.13, Django 5.x
- **Database:** SQLite
- **Frontend:** Bootstrap, HTML5, CSS3
- **Testing:** Django Test Runner (`unittest`)

## Getting Started

### Prerequisites
- Python 3.11+

### Installation & Run

```bash
# 1. Create and activate virtual environment
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# 2. Install dependencies
pip install -r requirements.txt

# 3. Apply database migrations
python manage.py migrate

# 4. Seed database with mock items, users, and reviews
python manage.py seed_data

# 5. Start development server
python manage.py runserver
```

Open `http://127.0.0.1:8000/` in your browser.

### Default Credentials (Generated by `seed_data`)

- **Superadmin:** `admin` / `admin123` (Full admin and auction control)
- **Auctioneer:** `arverezo` / `arverezo123` (Can start and close auctions)
- **Bidder:** `licitalo` / `licit123` (Regular logged-in user)

### Running Tests

```bash
python manage.py test
```

# Régiségek Online Aukciós Háza

Python és Django alapú webalkalmazás régiségbolt és online aukciós ház üzemeltetésére. A rendszer támogatja a műtárgyak kategóriák szerinti böngészését, az árverező által felügyelt licitálást, a jogosultságkezelést és a vásárlói vélemények kezelését.

## Funkciók

- **Műtárgykatalógus és szűrés:** Tárgyak böngészése (festmény, ékszer, porcelán kategóriákban), keresés és szerveroldali lapozás.
- **Aukciós és licitrendszer:**
  - Licitvalidáció: az új ajánlatnak szigorúan nagyobbnak kell lennie az aktuális árnál.
  - Regisztrációhoz kötött licitálás: csak bejelentkezett felhasználók tehetnek ajánlatot.
  - Árverező szerepkör: külön jogosultsággal rendelkező felhasználó indíthatja el és zárhatja le a licitet.
  - Lezárás után megjelenik a nyertes felhasználó és a leütési ár.
- **Adminisztráció:** Django Admin felület a termékek CRUD műveleteihez és a megvásárolt tételek áttekintéséhez.
- **Kapcsolat és vélemények:** Véleményküldő űrlap a korábbi bejegyzések publikus listázásával.
- **Tesztek és hibakezelés:** 5 Django `TestCase` egységteszt a licitlogikára és szerepkörökre, valamint egyedi 404-es hibaoldal.

## Technológiák

- Python 3.13
- Django 5.x
- SQLite adatbázis
- Bootstrap, HTML5, CSS3
- Django TestCase keretrendszer
